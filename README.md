## 🎮 Run the Game

First, clone the project:

```> git clone git@github.com:matdomis/game-of-life.git ```

Second, let's install some requirements:

```> cd game-of-life ```

```> pip install -r requirements.txt ```

Now the fun part:

```> python3 game.py ```

## ⌨️ Controls

| Key         | Action                      |
|-------------|-----------------------------|
| `F10`       | Reset the grid              |
| `F11`       | Toggle fullscreen           |
| `+ / -`     | Increase/decrease spawn rate |
| `ESC`       | Quit the game               |
